# PDF Compressor Pro

Локальное веб-приложение для сжатия PDF-файлов **без ограничений по размеру** с гибкими настройками.

## Возможности
- **Без лимита по размеру файла** — потоковая загрузка чанками по 1 МБ (поддерживает файлы по 500 МБ, 2 ГБ и более).
- **Сжатие до точного размера** — укажите желаемый вес в МБ или КБ (или процент от исходного файла), и алгоритм автоматически подберёт оптимальные DPI и качество.
- **Выбор цветового режима**:
  - **В цвете (RGB)** — сохраняет оригинальную палитру.
  - **Оттенки серого (Grayscale)** — плавный серый режим.
  - **Чёрно-белый (Ч/Б скан)** — контрастный монохромный режим с регулировкой порога яркости (отлично подходит для сканов и документов).
- **Два алгоритма сжатия + Авто-режим**:
  - **Умное сжатие (Smart)** — пережимает встроенные изображения, чистит дубликаты объектов и сжимает потоки, сохраняя выделяемый текст и векторную графику.
  - **Полная растеризация (Rasterize)** — конвертирует страницы в оптимизированные изображения выбранного DPI для максимального сжатия сложных PDF.
- **Визуальное сравнение «До / После»** — полистайте страницы и сравните качество прямо в браузере перед скачиванием.

## Быстрый старт

```bash
cd pdf-compressor
make up
```

Откройте в браузере: **http://localhost:8080**

### Альтернативный запуск через Docker
```bash
cd pdf-compressor
make docker-up
```
